# Synthetic university datasets

CSV files generated by `ml/models/student_results_dataset_and_models_training.py` (`OUTPUT_DIR = university_data`).

Regenerate from the repository root:

```bash
head -n 342 ml/models/student_results_dataset_and_models_training.py | uv run --directory backend python -
```

Run that command from the repo root so output lands in `./university_data/`.

Default run uses `TOTAL_STUDENTS = 10000` in the training script.
