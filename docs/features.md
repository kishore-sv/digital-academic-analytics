# Features

## Institution Admin Portal

- Institutional dashboard with KPIs (students, faculty, CGPA, pass %, at-risk %)
- Department and course analytics
- ML prediction interface (performance, pass/fail, risk)
- Risk distribution monitoring
- Student management
- Institutional reports

## Student Portal

- Academic overview with CGPA/SGPA
- ML-powered predictions (end-term performance, pass probability, academic risk)
- Improvement guidance with risk factors and recommendations
- Academic goal setting (CGPA/SGPA targets with progress tracking)
- Personal reports

## Faculty Portal

- Assigned students overview
- Student performance and predictions
- At-risk student monitoring
- Reports for assigned students

## Parent Portal

- Child's academic overview (simplified, non-technical language)
- Performance and prediction visibility
- Improvement areas and reports

## ML Components

All predictions use trained project models on synthetic data. UI displays:
- "Predicted End-Term Performance" (not model names)
- "Likelihood of Passing" (not probability jargon)
- "Academic Risk" (not "risk scoring engine")

Admin/faculty can optionally see more prediction details.
