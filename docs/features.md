# Features

## Institution Admin Portal

- Institutional Analytics Dashboard
- Department Analytics
- Subject Analytics
- Student Academic Profiles
- Performance Analytics
- Performance Prediction
- At-Risk Student Detection
- Reports
- Alerts and Trends inside Reports
- User Management (students, faculty, parents)

## Student Portal

- Academic Profile
- Performance
- Results
- Performance Prediction
- Improvement Areas
- Goal Setting
- Personalized Academic Planning
- Reports

## Parent Portal

- Child Academic Profile
- Performance
- Results
- Prediction
- Improvement Areas
- Reports

## Faculty Portal

- Assigned Students
- Student Academic Profiles
- Performance
- Prediction
- At-Risk Students
- Improvement Areas
- Reports

## Notes

- There is **no HOD login**. Institution Admin directly views department-wise analytics.
- There is **no platform-admin role**. Each institution is an independent tenant.
- Only Institution Admin can sign up. Students, faculty, and parents are created by the admin.
