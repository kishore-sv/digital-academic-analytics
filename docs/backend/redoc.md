# Interactive API reference (ReDoc)

Open the **[ReDoc UI](redoc.html)** in a new tab.

It loads the OpenAPI schema (`openapi.json`) generated from the FastAPI app. You can inspect every path, query parameter, request body, and response model.

!!! note "Try requests"
    ReDoc on GitHub Pages is **read-only**. To call the API from a browser, run the backend locally and use [Swagger UI](http://localhost:8000/docs) after `POST /api/v1/auth/login`.
